聆听我声 · 沃雅妮莎 — v3.5.5 双版本

亮版名称：聆听我声 · 沃雅妮莎 · 亮
暗色版名称：聆听我声 · 沃雅妮莎

一、安装
完整解压对应 ZIP。亮版项目文件夹为 Vodyanitsa_Listen，暗色版为 Vodyanitsa_Listen_Dark。
将整个项目文件夹复制到 Wallpaper Engine 安装目录下 projects/myprojects/，重新打开编辑器，在已有项目中选择对应名称。
project.json 是配置文件，不是可导入的模型或图片素材。另一种创建网页壁纸的方式是将项目内 index.html 拖到编辑器首页的“创建壁纸”；导入会产生项目副本，请核对用户属性。

二、预览
确认角色、发丝、眨眼、设置、台词、来信和听歌页面正常。首次播放音频可能需要点击画面。
亮版设置显示 v3.5.5，暗色版显示 v3.5.5 Dark.2。

三、发布与更新
首次发布：在对应工程内选择“创意工坊 → 在创意工坊分享壁纸”，核对名称、预览图、分级及可见性后发布。
更新已有作品：先把旧工程完整备份到发布工程以外的位置，继续使用原发布工程，并保留它的 workshopid。不要直接用本下载包的 project.json 覆盖已有发布配置；需要合并用户属性时请保留原作品 ID。
本下载包不含作者的 workshopid。两个版本独立发布时，各自保留发布后生成的配置，避免用同一个 ID 相互覆盖。

四、文件
index.html 为网页入口，project.json 保存工程配置，preview.jpg 为预览图，assets 包含图片和音频。请保持完整目录结构。
离线单文件 HTML 在同一 GitHub Release 中另行下载，不需要其他素材文件。
