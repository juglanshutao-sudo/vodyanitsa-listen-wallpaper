# 仅调整明暗

把“像这张一样暗一点”识别为明暗参考，不能自动替换素材或改变构图。参考带 UID、字幕、角标、录屏边框时，仅分析光照，不加入运行时资源。

## 流程

1. 确认目标场景/人物版本，继承明确范围，不把局部调整擅自扩到全局。
2. 保存基版哈希及同状态画面，比较参考和当前画面的暗部、中间调、亮部与主光方向。
3. 裁切不同时比较对应语义区域，采样排除 UID/字幕。直方图只辅助判断，不能仅靠全图分位数匹配不同构图。
4. 优先修改输出 RGB，保留 alpha、UV、蒙版生成、位移和素材字节。只调亮度时等比例缩放 RGB 保留色相，明确要求色调变化时才另行调色。
5. 保留主光方向与暗部细节，不把暖光压灰或暗部压死；按要求区分人物亮部与环境，不默认全图盖黑色。
6. 同一场景的底图、头发、衣物、皮肤补片、闭眼图与嘴型使用一致处理。
7. 核对范围，检查不应变化场景、位移极值、半闭眼与唱歌状态。

## 渲染链位置

在纹理采样、局部补片、口型等合成之后处理颜色。蒙版仍从原始素材生成，避免调暗导致颜色阈值改变抠图边界。最终合成后调色时明确 UI 是否参与，通常保留字幕和设置可读性。

Canvas 2D 使用 filter 或合成状态时，用 save/restore 限定作用范围；不能让设置泄漏到后续主页面或 UI 绘制。设置目标场景判断，并确认入口确实加载图片、调用渲染函数，而非仅定义一个未执行的函数。

逐层调色时使用同一函数与参数，并实际检查半透明交界。非线性调色与 alpha 混合一般不能交换顺序；逐层同函数不一定等于整帧调色。发生接缝时优先使用场景合成后的独立颜色处理阶段，不用改坏蒙版掩饰色差。

```glsl
if (isTargetScene) {
    float luma = dot(color.rgb, vec3(0.2126, 0.7152, 0.0722));
    color.rgb *= exposureCurve(luma);
    // 保持 alpha、采样坐标与运动参数。
}
```

按当前素材校准曲线，不复制历史系数。保持纹理编码、线性颜色空间处理及显示转换一致；不把 sRGB 近似亮度当成测量到的真实曝光量。

## UID 与范围验收

- 比较所有素材哈希，确认参考及派生像素未混入工程或单文件 HTML。
- 对不应变化场景做同状态像素对比，对目标场景检查覆盖与边缘。
- 实际查看右下角等敏感位置。原素材本来有 UID 时需指出并按用户授权处理，不能用“未新增素材”冒充去除了原有 UID。
- 同步工程、HTML、版本标记；用户没有要求新分支时更新原暗色版身份。
