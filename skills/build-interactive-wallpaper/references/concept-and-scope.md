# 概念与范围

选出三个核心：值得停留的主画面、有剧情意义的物件、承载情绪的声音。分开被动待机与主动探索，让结束后的画面能回到安静状态。

| 方向 | 实现方式 | 先检查 |
| --- | --- | --- |
| 活起来的瞬间 | 发丝、衣摆、纸张、水面、光影各自运动 | 像素到底属于哪个物体 |
| 可停留的空间 | 远景、中景、角色、前景轻微视差 | 裁切与运动后露出的空洞 |
| 物品保存故事 | 相框、书、信、乐器进入对应回忆 | 热区、返回路径和台词归属 |
| 剧情片段 | 逐句推进，回答选项控制下一段 | 必须回答的节点不能被自动越过 |
| 一幅画的不同时间 | 日夜、天气或灯光缓慢变化 | 不任意改写剧情特定时间 |
| 角色关注用户 | 短暂视线、局部回应、低频待机动作 | 避免持续追踪鼠标造成机械感 |
| 声音影响环境 | 乐句带动轻微光影或装饰 | 不把所有物体做成音量计 |
| 留下探索痕迹 | 已读标记、展开的信、曲目书签 | 确认是否需要保存及重置 |

## 剧情事实与原创设计

- 观看用户提供的相关片段，记录时间点、说话人、原句与画面对应。未观看不能说已经核实。
- 需要补充设定时按当前检索要求核实，清楚标明原创设想，不捏造官方剧情。
- 选取少量情绪完整片段，安排起点、参与方式与收尾，避免只堆特效。
- 将用户否决的项目记录为当前作品约束，例如不加流星、去掉萤光；不迁移成所有作品的永久禁用规则。

## 小型项目记录

维护基版与父版本、实际素材/仅参考文件、尺寸和裁切、图层用途、允许修改范围、已认可动作、状态表、音频分段、待解决问题、验证方式。不要把云端交付状态当成用户电脑上的安装状态。

局部修改先保留可复现对照：同时间、相机、风力、表情与随机种子。必要时用测试入口固定待机状态，避免把自然动作差异误判成改色或蒙版问题。
