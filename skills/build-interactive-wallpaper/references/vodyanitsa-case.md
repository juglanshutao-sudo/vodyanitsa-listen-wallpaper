# 沃雅妮莎案例

本页记录经验和该作品的偏好，不是新作品的固定需求。继续工程时以当前文件与最新用户要求为准，不仅依历史版本名判断状态。

## 作品结构

- 主页面：清晰背景、人物、前后头发分开，持信，保留肩部纹样。
- 约定与歌声：原声对话、可提前点击的音符、唱歌 BGM、两种旅行者听歌画面。
- 藏信室：画框进入回忆/来信，内容页按用户要求禁用再次跳转，始终可返回。
- 一次点击推进一句，旅行者回答选项点击后才触发下一段角色对白。
- 默认音乐与唱歌音轨分工，避免对白配乐与默认 BGM 叠加。
- 作者声明启动显示五秒，可永久关闭，字号与台词同步；作者和账号由用户确定。
- 字体和底部避让可调，去掉用户不需要的萤光，不添加流星。

## 返工教训

| 问题 | 可迁移经验 |
| --- | --- |
| 头发、肩膀和信一起动 | 先按物体归属分层，不能把连通区域当一个运动物体 |
| 用户纠正圈中是袖子而非头发 | 实际看标注，不凭文字和颜色猜测 |
| 头发露洞、底部拉伸 | 补全遮挡区，保持共享边界变换和平滑衰减 |
| 左右波浪不合偏好 | 保留用户认可的同步上下运动 |
| 额头补片像多余头发 | 同查 alpha 与肤色，不仅扩大本体蒙版 |
| 花纹只补一部分 | 对照完整原图，不能把碎片存在当完整恢复 |
| 唱歌背景空间波动 | 只移动分离发丝，保持底图稳定 |
| 网页字正常、桌面字太小 | 桌面尺度与统一字号是交付的一部分 |
| 设置在任务栏下、点击异常 | 检查安全区、本地按钮和宿主兼容 |
| 两份相同工程 | 一个当前身份，明确变体需求才新建 |
| 暗色参考有 UID | 只改输出 RGB，参考不进入运行时资源 |

## 历史方案边界

主页面曾采用背景、后发、固定身体、前发的 WebGL 分层；听歌页采用静止合成底图、独立头发和旅行者/派蒙衣物层。局部从源图恢复额头与肩带花纹，收紧蒙版去掉信封残边。

暗色分支先压低主页面人物亮部，再分别调暗两种听歌画面中间调并保留暖光，工程与 HTML 同步。验证含实际着色器渲染和素材哈希一致，不构成 Windows Wallpaper Engine 实机验证。

不要复制历史蒙版坐标、纹理尺寸、眨眼秒数或调色系数到新构图。记录过修复措施不代表所有边缘已完美，继续复现用户指出的实际缺陷。
