# 交互与音频

## 显式状态

将页面与播放器状态分开，至少记录 `page`、`phase`、`lineIndex`、`awaitingChoice`、`variant`、`paused`。为每句台词设稳定 ID，保存说话人、字幕、音频、下一节点；按需增加音符、已读和音乐状态。

| 状态 | 事件 | 结果 |
| --- | --- | --- |
| 主页面待机 | 点击剧情入口 | 进入对应台词/场景 |
| 台词播放 | 单次推进 | 停当前句，播下一句 |
| 等待回答 | 点击回答按钮 | 记录选择后触发对应台词 |
| 回忆选择页 | 点击有效画框 | 进入对应场景并播放所属台词 |
| 来信内容页 | 推进、返回 | 按要求禁用画框名称及二次跳转 |
| 唱歌 | 返回、换人物、暂停 | 协调画面与音乐进度 |

仅实现用户需要的节点，表格不是所有作品的固定功能清单。

## 避免跳句与过期回调

- 统一下一句入口，处理事件冒泡，防止一次点击同时命中字幕与背景。
- 等待回答时，背景点击和音频结束不得越过节点；回答触发后锁一次，防止双击播放两段声音。
- 场景转换使用短暂锁或状态令牌，返回时使旧 `ended` 回调、淡入任务、计时器和口型驱动失效。
- 子场景提供可见返回，恢复目标音乐和热区；不能只换背景却继续播放上一段台词。
- 提前点击物件跳台词、再次点击进入唱歌等操作编码为显式转换，不堆互相矛盾的布尔值。

## 音频分工

区分默认 BGM、唱歌曲目、人声对白、短音效。用户指定视频时间点时实际试听并标记入点/出点，不切断前后词。

1. 判断对白是否混有原配乐。
2. 有可用工具时分离人声，试听音乐残留、齿音、混响与尾音，保留原音轨。
3. 无合格纯人声时，选对白期间压低/暂停默认 BGM，或播放剧情完整混音，并说明取舍；不声称未经验证的分离成功。
4. BGM 切换用短淡入淡出，避免两首音乐长时间重叠；对白期间按可懂度降低背景音量。
5. 暂停时记录哪些声音应恢复，不重新播放此前已结束的句子。

切换听歌视角/人物时，若用户希望继续聆听，保持歌曲时间连续；口型读取音频时钟，避免独立计时漂移。

## 设置与声音启动

持久化必要偏好，如音量、字号、作者声明和画面适配；用户需要时才保存探索进度。网页控制与 Wallpaper Engine 宿主属性映射到同一状态，处理缺省值和类型。

网页预览处理首次用户操作后启动音频，不把自动播放拦截当作资源损坏。

验收正常推进、快速点击、提前跳转、返回重入、等待回答、暂停恢复和人物切换。核对字幕/说话人/音轨归属及是否残留旧热区、旧声音。
