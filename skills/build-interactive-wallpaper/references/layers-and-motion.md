# 分层与动作

## 语义归属与遮挡

对交叠区域回答：像素属于谁、在谁前面、移动后露出谁。额头白色区域属于皮肤，肩带花纹属于衣服，发丝间白片可能是信纸；用源图和分层共同判断，不只用颜色阈值。

保留背景、固定本体、后发、前发、面部状态和必要遮挡补全。尺寸不同时建立明确坐标变换，不能拉伸“凑齐”。补全仅覆盖必要区域；无法从原图恢复的部分属于创作，保留原图以便回退。

## 故障定位

| 症状 | 先检查 | 修复与验收 |
| --- | --- | --- |
| 肩膀、信封随头发动 | 蒙版混入身体、纸面或边框 | 收紧语义边界，固定本体，检查最大风力 |
| 发丝黏住信封 | 前后层、发尖归属、边缘混色 | 保留真发尖，排除纸边残像，检查位移极值 |
| 额头黑/灰楔块 | 皮肤缺口、错误发丝 alpha、补片色差 | 用邻近同光照皮肤恢复，不能简单涂纯白 |
| 肩带花纹残缺 | 误删进头发层、恢复坐标偏差 | 从原画恢复到固定衣服层，检查完整图案 |
| 头发附近空间波动 | 扭曲了整张合成图 | 静止底图配独立活动层 |
| 大幅飘动露洞 | 补全不足、前后层变换不一致 | 按极值补齐，共享边界变换 |
| 多余头发、重影、接缝 | 底图残留旧发丝、alpha 叠加 | 清理原位置或使用补全底板，核对绘制顺序 |
| 底部奇怪拉伸 | 位移在很窄范围内急降为零 | 扩大连续衰减范围，查看底边纹理梯度 |
| 左右波浪不合要求 | 横坐标相位或左右不同步 | 根据用户偏好改共享时间相位 |

## 运动约束

- 发根、衣领、手持接触点位移趋零，自由度随距离平滑增加。头发、袖口、书页各自约束，不仅换同一函数的振幅。
- 用户要同步时共享时间相位，以空间权重产生幅度差；只有需要传播波时才让相位随空间变化。
- 用低频变化减轻机械感，不逐帧加入随机噪声。整体缩放不能冒充发丝飘动。
- 增大动作前检查完整周期、最大风力、画面边缘；避免用大面积固定覆盖让动作消失。

## alpha 与补片

确认 straight/premultiplied alpha 与混合方式一致。插值边缘可能带入旧背景色，扩大或模糊蒙版可能加重白边。

前后发若是同源互补拆分，按实际混合公式检查合成 alpha。只有确认拆分方式、覆盖顺序和混合模式后才能推导恢复式，不普遍套用 `rearAlpha/(1-frontAlpha)`。采样、颜色、几何边界也须一致。

恢复皮肤与花纹时匹配坐标、光照和边缘透明度，放到正确物体层里。不要仅恢复几个碎片就声称完整纹样已补齐。

## 眨眼、微笑与唱歌

- 眼睑连续覆盖稳定的眼球，避免压扁整块眼睛或闭合末段突然换图。
- 分别控制闭合、停留、睁开与眨眼间隔；已有项目的秒数不是通用生理标准，需按角色观感调整。
- 检查开眼、半闭眼、闭眼、复位时的睫毛、皮肤接缝、瞳孔和眉毛。
- 微笑仅作用于嘴角与小范围脸颊/眼睑，不扭曲整脸。
- 唱歌底图固定，独立头发和同行角色衣物蒙版；旅行者、派蒙的肩领接触点保持稳定。
- 优先用人声能量或已有对齐数据驱动口型，处理平滑、静音闭口及开合上限。混合音乐音量只是一种近似，不称为精确音素同步。
- 闭眼图、口型、补片和所有活动层使用相同场景调色，避免动作时色差。

## 验证

同时查看原尺寸局部与完整画面，检查静止、运动极值和覆盖完整周期的实际播放/渲染。可单独显示图层与 alpha；发现急剧拉伸时检查局部位移梯度。

只测试本次具体风险。旧参数没改不能证明旧问题已解决，静态图不能证明动画自然；缺素材或不能复现时明确限制。
