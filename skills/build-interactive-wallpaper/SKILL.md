# 剧情交互动态壁纸

将作品做成可长期停留的画面，让主动触发的剧情有明确开始、推进、返回和结束。保持原画构图、角色身份和已认可功能；把本次修改落实到具体素材、图层、场景和状态。

## 1. 找准基版和素材角色

1. 找到用户实际采用的工程，检查入口、资源及运行版本。沿用已知项目身份，不因压缩包名称相似就选旧版，不无故建立重复工程。
2. 将输入标记为：实际原画、透明分层、背景补全、动作参考、亮度参考、问题标注、剧情视频、音频。仅供参考的文件不得自动加入运行时资源。
3. 实际查看图片，核对尺寸、裁切、透明通道及坐标。棋盘格可能已烘焙在 JPG/PNG 中，不能凭外观认定透明。
4. 记录基版文件哈希及可复现画面。可用 `scripts/audit_project.py`；它只检查文件和入口，不证明画面质量。
5. 简短说明本次目标与范围后执行，不重新询问已有明确答案的参数。
6. 附件路径失效时，按当前可用能力找回已知工程或附件；必要文件确实缺失才向用户索取。不得假装看到了标框，不得凭文字重画原图冒充修复。

## 2. 选择最小有效修改

- 新作品：先确定主画面、交互物件、声音，再分层；只增加与叙事有关且适合长期观看的效果。
- 修复：先复现，定位蒙版、纹理、遮挡、位移或状态问题，保留已认可部分。
- 仅改亮度：保留源素材、UV、alpha、动作和声音，在目标场景的颜色输出阶段修改，使用明暗参考流程。
- 更换原画：重新核对图层、补片和热区，不能直接用不同裁切的参考替换材质。
- 独立风格版：用户要求“另做一版”才建立分支；后续更新该版时保留原身份。

## 3. 先稳定图层，再放大动作

先区分背景、后发、固定身体/服饰、面部、前发、前景物，按实际遮挡决定绘制顺序。

- 从头发运动区域排除袖子、肩带、手、信封和额头皮肤；不能只依颜色相似度划分。
- 补齐运动后会露出的区域，按最大位移验收。不要用大片静止区域掩盖缺口，让头发几乎不能动。
- 稳定发根、领口和手持接触点，给自由发梢与衣摆独立约束；共享边界的图层保持一致变换。
- 限制面部变化范围，保持眼球、脸型及皮肤连续；不能扭曲整张唱歌图来制造发丝运动。
- 静态对齐通过后再加风力，保留用户已确认的运动节奏，例如左右长发同步上下摆动。

生成或编辑位图时遵守当前图像工具要求；纯着色器、蒙版代码与交互按代码任务处理。不要为了调色无意重绘角色。

## 4. 明确剧情和音频状态

分开记录页面、剧情段、台词索引、等待回答、音乐、人物版本和暂停状态。

- 一次点击只推进一句。等待回答时，只有回答按钮才能继续。
- 返回、跳转、切换人物时取消旧音频、计时器及过期回调。
- 对没有后续行为的画框撤掉可点击名称和热区。
- 协调默认 BGM、唱歌 BGM 与对白。人声分离后必须试听；未分离或未检查不能称为“纯人声”。

## 5. 按本次风险验收

字幕、回答和作者声明使用统一字号体系，支持用户调整。设置留出任务栏空间、允许滚动，点击设置不能导航离开壁纸。处理首次音频启动及返回路径。

| 修改类型 | 最小有意义检查 |
| --- | --- |
| 动画/蒙版 | 静止、位移极值、完整周期；发根、额头、肩带、信封、底部和遮挡补全 |
| 明暗 | 同时间、相机、风力和表情的前后画面；所有相关渲染层及不应变化场景 |
| 剧情 | 正常推进、提前点击、双击、等待回答、返回重入、人物切换 |
| 交付 | 实际依赖、JS/着色器编译、ZIP 完整性、预览与工程一致 |

文件哈希一致不等于动画正确；静态截图不能证明动作自然；离屏渲染不等于 Wallpaper Engine 实机验证。准确说明实际验证层级。

## 6. 同源交付

从同一份最终工程生成 Wallpaper Engine 文件和网页预览。设置或诊断区域显示实际运行版本，更新脚本缓存标记。按桌面与交付资料检查依赖及完整写入。

按当前环境持久化规范保存；已有交付继续更新原身份。外部发布须有用户授权。最终说明改了什么、如何检查、哪些未验证，并提供可打开的工程和预览。

## 文件审计脚本

```bash
python3 scripts/audit_project.py /absolute/project --out /absolute/baseline.json
python3 scripts/audit_project.py /absolute/project --baseline /absolute/baseline.json --allow renderer.js --allow index.html --allow project.json --out /absolute/report.json
```

将报告保存在工程目录之外。允许列表只接受精确相对路径，不为让检查通过而扩大范围。脚本报告新增、删除与变化，对范围外修改返回非零状态。它跳过工具目录和隐藏文件，不能作为唯一打包清单。
